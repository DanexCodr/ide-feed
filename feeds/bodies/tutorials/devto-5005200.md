## How it works

It's a 3-step process. Ideally, put VS Code and your free chatbot side-by-side.

### Step 1: Copy context to clipboard

Specify the files you want to include in the context. You can use relative paths or glob patterns. Press "Enter" or click the "Generate" button to copy the context **straight to your clipboard**.

![Image description](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/g7xgb57tqh21cwkt8o67.webp)

Besides the files you specify, the context also includes the **project structure** and instructions on how to generate the output. You can enable/disable each section using checkboxes.

### Step 2: Paste context into your chatbot, along with your prompt

Send it and let it generate.

![Image description](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/tbilby6ytzs0yxey39i8.webp)

### Step 3: Apply the generated diffs

The chatbot will provide the diffs in a single code block. Copy them, and click "Apply Diffs" to apply them.

![Image description](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/qh3smafl784314iw5yrm.webp)

### Optional step (before step 3): Add more files to the context

If the chatbot wants to see more files, it will generate a code block containing the relative paths of the files. You can copy that block and click the "More Files" button to copy the contents of those files only to the clipboard, and paste it back to the chatbot.

> **A little behind-the-scenes:** Every animated WebP you see above was captured, edited, and exported using [GiffyPy](https://github.com/effessdev/GiffyPy), an all-in-one screen recording and video editing tool that I built myself!

So, that's basically what the extension does! A few other features:

* Live syntax highlighting and autocomplete
* Fuzzy diff matching
* All-or-nothing diff application to prevent partial or broken edits
* Session undo/redo for the last 10 diffs
* Warning before re-applying the same diff
* `.gitignore` enforcement & binary/size guards (skips ignored, binary, or large files)
* Per-project persistent settings & custom defaults through settings
* **And more!** (check out the [README](https://github.com/effessdev/reptclip-vscode) for full details)
