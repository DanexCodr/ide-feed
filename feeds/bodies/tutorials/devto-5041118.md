## Why Native Google Antigravity Primitives Change Research Workflows

Google Antigravity gives developers five composable customization layers that fit together cleanly:

1. **Progressive-Disclosure Skills (`SKILL.md`):** Each skill sits idle at `~50 tokens` (YAML frontmatter only) until the agent actually needs it—preventing context bloat across 8+ specialized workflows.
2. **Stdio MCP Servers (`mcp_config.json`):** Zero-hallucination deterministic tools for statistical hypothesis tests and live Crossref DOI lookups.
3. **Lifecycle Safety Hooks (`hooks.json`):** Pre/post tool-call guards that stop common Python research bugs before they happen.
4. **Always-On Rules (`rules/AGENTS.md`):** Strict provenance rules ensuring zero invented metrics and mandatory visual montage QA.
5. **Interactive HTML5 Studios:** Self-contained 60-FPS Canvas/SVG parameter explorers that let readers drag sliders over a paper's equations in real time.

## Inside the 8 `agy-*` Research Skills

Every script in `agy-research-kit` uses **PEP 723 inline `# /// script` metadata** executed via `uv run`, plus headless Chromium/Edge and `pymupdf` + `imageio[ffmpeg]`—meaning **zero system TeX or global FFmpeg installation headaches** across Windows, macOS, and Linux:

| Skill | What It Builds | Output Artifact |
| :--- | :--- | :--- |
| **`agy-interactive-paper-studio`** | Turns closed-form paper equations into a zero-backend 60-FPS HTML5/Canvas simulator | Standalone `index.html` |
| **`agy-ablation-stat-auditor`** | Recomputes exact **Wilson 95% score CIs**, **Fisher's Exact**, **McNemar paired p-values**, & leaderboard noise floors | Audit Markdown/LaTeX + JSON |
| **`agy-citation-doi-verifier`** | Verifies bibliographies against live **Crossref & OpenAlex REST APIs** and upgrades preprints to published venues | Traffic-Light DOI Audit |
| **`agy-figure-forensics`** | Adds numbered vector callouts, regime shading, and *Engineering Takeaway* cards onto 300-DPI paper plots | A4 Visual Anatomy PDF |
| **`agy-math-sandbox`** | Color-codes equations into operator blocks and runs deterministic NumPy/SciPy Monte Carlo verification | A4 Math Verification PDF |
| **`agy-trajectory-cinematics`** | Renders `1920x1080` H.264 `.mp4` animations pairing a live system state monitor with 2x2 real-time telemetry curves | 1080p `.mp4` + Narration `.md` |
| **`agy-graphic-story`** | Renders pure-code A4 **Vector SVG Technical Graphic Novels** with custom characters, blackboards, and verbatim scoreboards | A4 Vector Comic PDF |
| **`agy-frontier-gap-radar`** | Orchestrates OpenAlex + arXiv retrieval into an `N x 7` capability heatmap and novelty-checked research blueprints | A4 Frontier Gap Radar PDF |

## Built-In Stdio MCP Server & Lifecycle Safety Hook

When you install `plugins/agy-research-kit`, Antigravity automatically registers two guardrails that keep AI research honest:

1. **`research_audit_mcp.py` (Stdio MCP Server):** Exposes `verify_wilson_ci`, `verify_fisher_exact`, `leaderboard_noise_floor`, and `verify_doi_metadata` over JSON-RPC so the agent never guesses confidence intervals or p-values mentally.
2. **`stdlib_shadow_guard.py` (`PostToolUse` Hook):** Catches a classic Python footgun—if a script tries to write `numbers.py`, `statistics.py`, or `math.py` in your working directory (which silently crashes `numpy` and `scipy`), the hook flags it immediately.

## Install in 30 Seconds

**Windows (PowerShell):**
```powershell
git clone https://github.com/RobinaMirbahar/My-antigravity-research-skills.git
New-Item -ItemType Directory -Force -Path "$HOME\.gemini\config\plugins" | Out-Null
Copy-Item -Recurse -Force My-antigravity-research-skills\plugins\agy-research-kit "$HOME\.gemini\config\plugins\"
```

**macOS / Linux:**
```bash
git clone https://github.com/RobinaMirbahar/My-antigravity-research-skills.git
mkdir -p ~/.gemini/config/plugins
cp -r My-antigravity-research-skills/plugins/agy-research-kit ~/.gemini/config/plugins/
```

Run the self-contained verification suite anytime with:
```bash
uv run tests/test_skills_structure.py
```
