I just very recently made MDEZ++ (mdez), a lightweight Markdown editor. It is built with C++20 and the Qt Framework for the need for speed. Instead of a WYSIWYG (What You See Is What You Get) editor, or the polar opposite, a raw Markdown editor with a separate option to render it, it renders the raw Markdown as you type it on the right side of the screen. There’s essentially no knowledge required to use MDEZ++, not even knowledge of Markdown syntax. This is because of the Format menu, which allows you to apply Markdown syntax by clicking on unambiguous buttons. It can even render HTML files too, with almost the same workflow as Markdown files. It can also edit any other plaintext file format,  making it highly versatile.

![MDEZ++ (mdez), a lightweight markdown editor, editing its own README document](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/ldm1bm54h4uvawfs1rve.png)

## How to Use MDEZ++

When you open MDEZ++, you will see two panes: one on the left and one on the right. As you type Markdown on the left, it automatically renders on the right. The black bar separating them can be dragged with your cursor to resize the two panes.

Near the top of the window, there is a bar that contains all of the document tabs in the application. To create a new tab, click the + button on the far right side of the bar. The first tab will be automatically titled "Tab 1," and all subsequently created tabs will be titled accordingly. To delete a tab, click the red X next to the tab name. All other tab names will be automatically updated based on their new index caused by the deletion.

Arguably, the most important menu is the File menu. It consists of Open File, Save As, Save, Save All Files, Print, and Export as HTML buttons. The Save As, Save, Print, and Export buttons apply only to the selected tab. The Open File button will create a new tab to open the file in automatically, and that tab will be instantaneously selected for the user. The Save All Files button saves all of the documents from every single tab. If a tab has not already been saved, you will not be asked to set a save path when clicking the Save All Files button. Instead, only files that have already been saved, therefore giving them a save path, will be saved.

Another important menu is the Format menu, which contains many buttons that allow you to apply Markdown syntax without knowing Markdown. If text is selected, the syntax will be automatically applied to it. Whereas, selecting a syntax button with no text selected will apply the syntax with no text inside of it and automatically move your cursor to the appropriate location for you to continue typing. All of these buttons also have keyboard shortcuts that can be invoked from anywhere throughout the application. Below is a table that contains all of the syntax shortcuts in the Format menu.

| Format | Keyboard Shortcut | Description |
| :---: | :---: | :---: |
| Bold | `Ctrl+B` | Insert bold text |
| Italic | `Ctrl+I` | Insert italicized text |
| Heading 1 | `Ctrl+Alt+1` | Insert a level one heading |
| Heading 2 | `Ctrl+Alt+2` | Insert a level two heading |
| Heading 3 | `Ctrl+Alt+3` | Insert a level three heading |
| Horizontal Divider | `Ctrl+D` | Insert horizontal divider |
| Block Quote | `Ctrl+]` | Insert a block quote |
| Strikethrough | `Alt+Shift+5` | Insert strikethrough text |
| Link | `Ctrl+K` | Insert a link |
| Image | `Ctrl+Shift+I` | Insert an image |
| Code | `Ctrl+\` | Insert a code block |
| Inline Code | `Ctrl+E` | Insert inline code |

MDEZ++ also contains a Settings Menu, which saves across application instances and is automatically applied to each and every tab. The first setting is the Autosave setting, which can be enabled or disabled and have its interval altered through a number input in seconds. Its default is to be disabled. There are also separate options for the font point size of the editor and the font point size for the rendering pane. For the font point size setting of the rendering pane, other elements will be scaled accordingly relative to the font point size provided. Another setting is the end-of-line character option, which lets you choose between UNIX / macOS (LF) and Windows (CRLF) line endings. The final two settings are toggles for line wrapping in the editor and showing fun facts after application initialization.
