## What is a Skill in simple words

A Skill is not a plugin. It is instructions, scripts and resources in a folder. Your agent checks if it needs that skill, loads only that folder, follows the steps.

Anthropic started it. Now Google, Vercel, Cloudflare, Meta, even Prometheus ship one.

Why does it matter for you as a Next.js dev? You stop copying the same prompt in Claude Code, Codex and Cursor. You write the skill once in `SKILL.md`. That is it :)

Below are 10 trending repos, with real stars, real use cases and links. Save this for later.

### 1. Cloudflare security-audit-skill - 66K stars, 2,085 today

**What I found:** This skill turns your coding agent into a security auditor. Six phases: Recon, Coverage-led hunting, Candidate validation, Structured output, Independent record verification, Target-neutral reporting.

It writes `findings.json` and `coverage-ledger.json`. Fresh agents try to disprove each finding. That is how Cloudflare built their vulnerability harness.

**Use case for you:** If you ship auth in Next.js, run this before you push. Even phases 1 and 2 help a lot.

Repo: [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)
