What is programming for me today? And what could it have been, back then?

## The 10 PRINT kid

When I was a kid there was the Commodore 64. I remember these lines:

```basic
10 PRINT "HELLO"
20 GOTO 10
```

`PRINT` wrote text on the screen, and `GOTO` made the program jump to a specific line. Together they created an infinite loop: the screen filled with text forever. For a kid, it was magic.

Later came Windows 95 and Windows 98. I loved to tinker: I opened every folder, clicked everything, just to see what was inside. I was a lively kid, and my parents didn't have much patience for my curiosity. The world was different then.

Then, in the 90s, I had to start working. No studies, no university. I read a little here and there, while the world changed: Google arrived, the web exploded, and new languages appeared everywhere.

## The 90s web

And then there was the old web. A homepage in 1998 looked like this:

```html
<html>
<head>
  <title>My website in 1998</title>
</head>
<body bgcolor="#000080" text="#FFFFFF">

  <center>
    <h1><font face="Comic Sans MS" color="yellow">Welcome to my Home Page!</font></h1>
    <marquee>Under construction - Last update: 1998</marquee>
  </center>

  <table border="1" width="100%">
    <tr>
      <td><a href="photos.html">My photos</a></td>
      <td>Hi everyone, this is my first website!</td>
    </tr>
  </table>

</body>
</html>
```

`<center>`, `<font>`, `<marquee>`, tables for everything... Today they are almost all deprecated, but back then this was the web.

## From BASIC to the modern web

The same idea, a message on the screen, looks very different today.

**HTML:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My website today</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <header>
    <h1>Welcome to my website!</h1>
  </header>

  <main class="grid">
    <nav><a href="photos.html">My photos</a></nav>
    <p>Hi everyone, this is a modern website that adapts to smartphones.</p>
  </main>

</body>
</html>
```

**CSS:**

```css
h1 {
  color: green;
  font-family: monospace;
}
```

**JavaScript:**

```js
for (let i = 0; i < 10; i++) {
  console.log("Hello, world!");
}
```

Same curiosity, new tools.

## Tinkering again, at 53

Today I'm 53. I work in a factory during the day, and for about a year I've been tinkering again in the evenings, like a kid. It's the most beautiful thing in the world. It's stimulating, especially for the mind.

Code is like life. Every day something breaks, and almost always there is a way to fix it. Code is my daily life now.

I wrote this article because code makes me feel free. It makes me feel like myself. Yes, I get help from AI, otherwise I'd still be staring at the word "JavaScript". But the curiosity, the ideas and the late nights are mine.

## For those who believe

This article is for anyone who believes in it all the way. Code has no age. It's a friend. And like with every friend, sometimes you argue with it. 😄

If you started late, or you're starting now: open the folder, click everything, break things, fix them. That kid with `10 PRINT` is still inside you.
