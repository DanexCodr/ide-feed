## A raw file and clean Markdown  aren't the same to an AI.

Sygal normalizes every document into one clean, structured output your AI can actually work with. What that changes depends on where the file comes from.

### 2 to 7x lighter, where it counts

A scan, a screenshot, a scanned PDF or a web page carries a lot your AI pays to read but never uses: pixels, layout, markup. Converted to text, the same content can run roughly 2 to 7x lighter on tokens, and the model reads what matters. YouTube links come in as clean transcripts, ready to summarize or search.

The gain is largest on visual and web content; exact figures vary with each file.

### One clean, consistent output

Already-structured files get a different win: Sygal standardizes them into the same clean Markdown and JSON as everything else. One predictable output for your whole pipeline, ready to parse, search and reuse, with no format-by-format handling.

Whatever a document starts as, it ends the same way: clean, structured, and ready for your AI.
