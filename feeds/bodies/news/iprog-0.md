Meet Stringman, a cable-driven robot designed for domestic settings. Working from above, a gripper picks up objects from floors too cluttered for any wheeled or legged robot to navigate and effectively results in a self-tidying room.  Watch Stringman in action in this video: VIDEO Devised by engineer Nathaniel Nifong is available to buy through [Neufangled Robotics](<https://neufangled.com/>). Stringman can lift objects up to 2 kilograms and can be installed in rooms up to 7 metres wide, as long as there are wooden studs or structural columns to screw into. It can lift and can be teleoperated from anywhere.  Stringman currently utilizes a custom control stack using one model for identifying targets, and lerobot trained models for grasping tasks. Dropoff locations are specified by attaching April tags to bins such as the laundry hamper. A procedure combines these for continuous target-pick-and-place. The system is open-source, runs privately and offline on a local network, and loads quickly on modest hardware. The Stringman motion controller is the brain of the robot, running headless on a host machine. Several control methods are available including a maneuver API (code as policy), lerobot control, or MCP server control.  A web-based UI allows 3D visualization of the workspace, tension monitoring, and automatic calibration. The robot can operate in LAN-only local mode where no data leaves your network, or in a cloud telemetry mode that uses Neufangled Robotics' servers to allow secure access to your robot from anywhere.A cloud-connected robot can also be shared with other logged in users for remote operation. Supplied as a set of pre-assembled parts, Stringman costs $795 plus shipping, It is available with a lead time of 4 weeks for delivery to US and Mexico, United Kingdom, Japan, Korea, Australia, Vietnam and Taiwan. The project's official documentation and download links for the CAD design files, bill of materials, and print guide are maintained through the [Neufangled Documentation portal](<https://neufangled.com/docs/>) and the firmware and software stack for Stringman are also hosted on GitHub at [cranebot3-firmware](<https://github.com/nhnifong/cranebot3-firmware>).
