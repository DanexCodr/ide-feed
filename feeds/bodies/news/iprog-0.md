Microsoft has released .NET 11, with improvements across C# 15, ASP.NET Core, .NET MAUI, and Windows development. The version has hundreds of runtime optimizations, more responsive SDK tooling, and less overhead in everyday commands.  .NET is the platform created from a combination of .NET Framework and .NET Core, including C# and F#. The previous release, .NET 10, was released in November 2025 as a long-term support release that will be supported for three years. .NET 11 will have two years standard term support (STS).  There are no new major changes from the version of .NET that was released as Release Candidate 2, as it locked down the feature set and core APIs. However, this version has some stability hardening, critical bug fixes, and documentation updates, and comes with updated minimum CPU instruction set requirements for x86/x64 and Arm64. It also has default SDK tooling, Visual Studio 2026 support, and container-based images out of the box without requiring preview or insider opt-ins. VIDEO Taken as a whole, .NET 11 now uses C# 15 as the default language version for projects targeting .NET 11, with union types as one of its biggest additions. Union types mean a value can be one of a declared set of case types, with conversions from those types and exhaustiveness checking in switch expressions. As the name suggests, exhaustiveness checking ensures a switch statement or expression handles every possible value of a given type (such as a union type, enum, or boolean). The result type tells a caller which outcomes it needs to handle, so there's no need to use object or an unrelated base class just to put those outcomes behind one return type. C# 15 adds support for closed hierarchies. A closed hierarchy is one in which all of the derived types are contained in a single assembly. Marking a class or record as closed implicitly makes it abstract, and means no external assemblies can derive from it. Closed hierarchies also benefit from additional exhaustiveness checking in switch expressions.  C# 15 also adds collection expression arguments that let you pass constructor or factory arguments without giving up collection expression syntax. Another highlight of .NET 11 is the addition of a native AOT (Ahead-Of-Time) CLI host and a warm MSBuild server. This keeps a warm MSBuild worker between CLI invocations, which reduces startup overhead for repeated build and test commands. The Native AOT CLI host has been added to enable near-instant startup for common CLI invocations. Elsewhere, ASP.NET Core brings asynchronous validation, OpenAPI 3.2, and new capabilities for Blazor and SignalR applications. There are experimental Blazor AI components that integrate with the Agent User Interaction Protocol (AG-UI) for advanced agentic web experiences, and the Microsoft Extensions.AI (MEAI) adds a way to build AI-powered, agentic applications. Finally, .NET MAUI adopts CoreCLR as its default runtime and improves XAML iteration and native control. Its libraries add built-in Zstandard compression, simpler process execution, richer JSON support, and new ways to work with in-memory data without copying it first. .NET 11 is available for download now.
