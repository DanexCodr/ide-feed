### Book Watch

[ Murach's Python Programming, 3rd Ed (Murachs) ](<https://www.i-programmer.info/book-watch-archive/19166-murachs-python-programming-3rd-ed-murachs.html>)   

This book takes a self-paced approach to cater for new and existing programmers. If you already know other languages, you can move quickly through the familiar to focus on the new as you learn Python faster. Joel Murach and Michael Urban start with an 8-chapter introduction course to Python that gets as far as using functions and modules to organize a program that uses file I/O to read and write data. Section 2 builds on that foundation with additional skills every Python programmer needs. Section 3 dives into object-oriented programming. And section 4 brings it all together as you build realistic database and GUI applications. <ASIN:B0H1ZNKWDD > [ \+ Full Story ](<https://www.i-programmer.info/book-watch-archive/19166-murachs-python-programming-3rd-ed-murachs.html>)  

* * *

[ Fundamentals of Computer Graphics, 5th Ed (CRC Press) ](<https://www.i-programmer.info/book-watch-archive/19159-fundamentals-of-computer-graphics-5th-ed-crc-press.html>)   

This book provides a comprehensive introduction to basic computer graphic technology and theory. Focusing on geometric intuition, Steve Marschner and Peter Shirley give the necessary information for understanding how images get onto the screen by using the complementary approaches of ray tracing and rasterization. It covers topics common to an introductory course, such as sampling theory, texture mapping, spatial data structure, and splines. It also includes a number of contributed chapters from authors known for their expertise and clear way of explaining concepts. <ASIN:0367505584 > [ \+ Full Story ](<https://www.i-programmer.info/book-watch-archive/19159-fundamentals-of-computer-graphics-5th-ed-crc-press.html>)  

* * *

[ Unreal Engine 5 for Beginners (Packt) ](<https://www.i-programmer.info/book-watch-archive/19156-unreal-engine-5-for-beginners-packt.html>)   

Subtitled "A step-by-step guide to building your first playable third-person game", this book teaches Unreal Engine 5 via a hands-on game project, progressing from editor basics and Blueprints to AI, UI, cinematics, polish, and packaging.   
Authors Zhenyu George Li , Charles Shih-I Yeh and Michael Oakes begin by showing how to install Unreal Engine, setting up a first project, and exploring the editor to build and light levels. As the book progresses, readers will create gameplay with Blueprints, import and animate a player character, and configure controls with Enhanced Input. They'll then develop AI enemies and implement gameplay rules, mission objectives, and win-and-lose conditions. <ASIN:1806105918 > [ \+ Full Story ](<https://www.i-programmer.info/book-watch-archive/19156-unreal-engine-5-for-beginners-packt.html>)
