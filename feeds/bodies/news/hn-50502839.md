Inspired by [this Reddit post](https://www.reddit.com/r/vexillologycirclejerk/s/Bqage66kXN): if the
        flag is the letter X, what does the rest of the alphabet look like?
        [Read the blog post about making this font](https://digitalseams.com/blog/making-a-font-for-the-jamaican-flag-alphabet?ref=bobbiec.github.io).

This text box contains ordinary text that you can select, copy, and search. The colors and shapes are built
        directly into the font!

The Connected Variant joins letters together, using contextual font features to match background colors between
        letters and connecting certain glyphs.
        [Learn more about how this font works](https://digitalseams.com/blog/making-a-font-for-the-jamaican-flag-alphabet?ref=bobbiec.github.io).
