**[Muru](https://github.com/muruhq/muru)**. Graham Dumpleton started [mod_wsgi](https://modwsgi.readthedocs.io/) 20 years ago, and has been thinking about the ideal way to serve Python web applications in production ever since.

Muru is his new, AI-assisted Rust server that aims to provide the best possible tools for running ASGI and WSGI Python apps both in development and production.

As [he did with wrapture](https://simonwillison.net/2026/Sep/11/wrapture/), he's been publishing an extraordinarily detailed account of the project as he works on it - as part of his development process.
