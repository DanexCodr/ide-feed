Python 3.15 has been released with updates including explicit lazy imports, new built-in types, and an upgraded JIT compiler.  Python regularly comes top of league tables for popularity, because it combines being easy to use, understandable, and powerful through its treatment of everything as an object- including class.  The addition of lazy imports is one of the key additions, and should improve startup times for large Python applications. This happens because of the time needed on a module import to locate the file, read it from disk, compile it to bytecode, and execute all top-level code. For applications with deep dependency trees, this process can take seconds, even when most of the imported code is never actually used during a particular run. Until now, developers have used the technique of moving imports inside functions or using importlib to load modules on demand. Python now has a way to mark imports as lazy, meaning Python defers the actual module loading until the imported name is first used. This gives you the organizational benefits of declaring all imports at the top of the file while only having to wait for the loading of modules you actually use. Python creates a lightweight proxy object and the actual module loading happens transparently when you first access the name: The next addition is a new data type, frozendict, the frozen dictionary. This adds an immutable dictionary that doesn't allow the adding, removing or changing of elements once created, but can be used as a key. This is useful for storing fixed app settings or API endpoints so they can't be accidentally or maliciously changed. It also supports thread-safe reading as multiple threads can read from it concurrently without the risk of race conditions or changes.  Another addition is the sentinel() built-in type . These preserve their identity when copied, support use in type expressions with the | operator, and can be pickled when they are importable by module and name. Sentinel types can be typechecked properly, and used in cases such as default values for function arguments, or return values from functions when something is not found or unavailable. Until now, Python programmers have used the special value None, but the new type will be useful when an alternative sentinel value is needed that is distinct from None since None is a valid value in that context. Another improvement of note is the addition of Tachyon, a statistical sampling profiler. This profiler enables low-overhead performance analysis of running Python processes without requiring code modification or process restart. Unlike deterministic profilers (such as profiling.tracing) that instrument every function call, the sampling profiler periodically captures stack traces from running processes. This approach provides virtually zero overhead while achieving sampling rates of up to 1,000,000 Hz, making it the fastest sampling profiler available for Python.  The experimental incremental garbage collector introduced in Python 3.14 has been suspended because it used too much memory, and this release reverts to the classic generational GC until further notice. Finally, The experimental JIT compiler has been significantly upgraded, with 7-8% geometric mean performance improvement on x86-64 Linux over the standard interpreter, and 11-12% speedup on AArch64 macOS over the tail-calling interpreter.  Python 3.15 is available now.
