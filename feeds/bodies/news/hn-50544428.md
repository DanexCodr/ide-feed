# A spreadsheet where every cell is *Python*.

Change a parameter and every value, plot and paragraph that depends on it updates.
        Nothing else reruns, nothing goes stale. Notes, a grid of cells and a dependency graph over one
        plain `.workbook.py` file.

`uvx reaktiv-workbook new --from welcome` or `pip install reaktiv-workbook`

Works with your stack: NumPy, pandas, scikit-learn, Plotly, Matplotlib, anywidget, and anything you can `pip install`.

## Explore faster, without the stale state.

### No hidden state

Cells update like spreadsheet formulas: change an input and everything that
          reads it recomputes, in dependency order. No “run all”, no stale variables, no out-of-order surprises.

### Everything on one screen

A spreadsheet-style grid puts inputs, intermediate results and plots
          side by side, so a whole analysis or dashboard fits on one screen instead of a long scroll.

### See why it changed

The dependency graph is drawn from your code. Follow a parameter to every
          value and plot it affects, or select a cell to see only its connections.

### Notes that stay true

Markdown with live values, LaTeX, sliders and figures. The explanation
          reads from the cells, so it cannot drift from the numbers.

### Share it as an app

`reaktiv-workbook run` serves the notes and controls as an
          interactive app for colleagues. Nothing to rewrite.

### AI in the loop

With `--mcp`, Claude Code, Cursor or any MCP client works in your
          live workbook while you watch: new cells, another approach, a plot. Every change is one undo step.

## Signals at the core

Underneath is [reaktiv](https://pypi.org/project/reaktiv/), a signals library for
          Python. Signals keep the state of modern UI frameworks consistent with very little code; here they keep a
          model consistent while you change it.

1. Reading is subscribing. A cell depends on exactly what it reads while it runs. Nothing to declare or wire up, and a branch that is not taken is not a dependency.
2. Only what is affected reruns. A change marks the cells that read it as stale; they recompute in dependency order, and a result that comes out the same stops the update there.
3. Lazy and cached. A derived value is computed when something needs it and reused until one of its inputs changes.
4. Side effects are explicit. Formulas only compute. Writing files, calling services and changing inputs happen in effects and actions, where you can see them.

```
# plain reaktiv, in any Python program
from reaktiv import computed, effect, signal

price = signal(3.5)
cups = signal(120)
revenue = computed(lambda: price() * cups())
report = effect(lambda: print(f"revenue: {revenue()}"))
# revenue: 420.0

price.set(4.0)   # revenue: 480.0
cups.set(120)    # unchanged: nothing reruns
```

### Input

State you change: a parameter, a slider, a list of rows.

### Formula

Derived from other cells in ordinary Python, from one expression to a pandas pipeline or a figure.

### Linked input

A suggested value derived from other cells that you can override, and reset.

### Resource

A value that arrives later: a file, a query, an API call. It reloads when its parameters change and reports loading and errors.

### Effect

Runs when what it reads changes: write a file, send an alert, log a result.

### Action

A step you trigger from a button or an agent, such as importing data or resetting a scenario. It can change inputs.
