The PHP development team announces the immediate availability of PHP 8.6.0. This release marks a major update to the PHP language.

PHP 8.6 comes with numerous improvements and new features such as:

- Partial Function Application
- Default values for readonly properties
- New Io\Poll API for monitoring streams
- New clamp() function
- New \Time\Duration class
- New SortDirection enum

See [what’s new in PHP 8.6](https://www.php.net/releases/8.6/en.php) for more highlights and examples.

Source downloads for PHP 8.6.0 are available on our [downloads page](https://www.php.net/downloads.php?source=Y).
  Windows source and binaries are available on the [Windows downloads page](https://www.php.net/downloads.php?os=windows).
  The list of changes is recorded in the [ChangeLog](https://www.php.net/ChangeLog-8.php#8.6.0).

The [migration guide](https://www.php.net/manual/en/migration86.php) in the PHP Manual lists new features and backward-incompatible changes in detail.

Kudos to all the contributors and supporters!
