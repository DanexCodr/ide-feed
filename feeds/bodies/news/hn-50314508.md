**phoria2** is a small, fast JavaScript library for 3D on the web - charts,
          labelled scenes, dashboards and product viewers, on a WebGL 2 renderer with an API you can
          learn in an afternoon. Designed for ease-of-use by agents and humans from the ground up!

- Everything you need PBR materials, instancing, points, lines, labels, picking, shadows, particles and glTF models.
- Light and quick No runtime dependencies, plain ES modules, and views that only draw when something changes.
- Tells you what to write Every option is validated, a mistake comes back as an error that details the fix - for you, or your coding agent.
- Open source MIT licensed. npm install phoria2, then find the code, the docs and a React example on GitHub.
