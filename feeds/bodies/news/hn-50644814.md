Even if it feels unintuitive, the price of an option does not depend on
whether you expect the underlying to moon or tank. Under some
reasonable market hypotheses, we can build a fully hedged portfolio by
holding the underlying and shorting the option. Since it is riskless,
by no-arbitrage assumption, it must return the same as the risk-free
interest rate. That allows to put together an equation (the
Black-Scholes equation), and solve for the option price (the
Black-Scholes formula).

## Hedged portfolio
[§](https://david.alvarezrosa.com/posts/deriving-black-scholes/#hedged-portfolio)

The trick of Black-Scholes is to build a fully hedged portfolio
combining the option and the underlying in the right proportion. By the
no-arbitrage hypothesis, its returns must be the same as the interest
rate r ⁣r\!r, and that way we can put together an equation.

If you short one option and hold Δ\DeltaΔ shares, then the two moves
cancel. This is a delta hedge.

Note that Δ\DeltaΔ changes with the stock price and time. The
portfolio is riskless only over an instant, and stays so only if it is
rebalanced continuously.
