## No runtime limits.

128 MB is all the memory a Cloudflare Worker gets. OpenOrange runs your Workers and Durable Objects on machines you choose, so the limits are your hardware's.

| Limit | Cloudflare Workers Paid | OpenOrange |
| --- | --- | --- |
| Memory per Worker or Durable Object | <s>128 MB</s> | Up to your machine's memory Node.js heap: up to about 4 GB by default, configurable |
| CPU time per request | <s>30 s default, 5 min max</s> | No cap |
| Cron, queue and alarm handlers | <s>15 min wall time</s> | No cap |
| Open connections per request | <s>6 at once</s> | OS limits |
| Storage per Durable Object | <s>10 GB</s> | No cap |
| Worker bundle | <s>64 MiB</s> | No cap |
| Node.js | <s>nodejs_compat subset</s> | Stock Node.js |
