## What is Java4Shell (CVE-2026-114938)?

Java4Shell is the name given to CVE-2026-114938. Early reports describe it as an unauthenticated remote code execution flaw in all Java 17 versions before 17.0.21.1, rated 9.2 (Critical) under CVSS 4.0. Oracle scores Java flaws under CVSS 3.1, where its highest Java SE score this month is 8.1, so the two figures may describe different issues. For reference, 9.2 under CVSS 4.0 is the same score PHP2Shell carries.

Further technical details are expected after Oracle's patch release. Until then, the vulnerable component and the conditions for exploitation are not public. We will update this post when they are.

## Is Java4Shell being exploited?

As of November 17, we have seen no reports of exploitation in the wild. Technical details are due later today, and exploitation can follow quickly once details are public, so patch now. We will update this post if that changes.
