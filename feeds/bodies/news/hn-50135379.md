This release will be the Reference Implementation of
version 28 of the Java SE Platform, as specified by
[JSR 403](https://openjdk.org/projects/jdk/28/spec) in the Java Community Process.

## Status

The [main line](https://github.com/openjdk/jdk/) is
open for bug fixes, small enhancements, and JEPs as proposed and
tracked via the [JEP Process](https://openjdk.org/jeps/).

Early-access binaries, under the GPL, are available [here](https://jdk.java.net/28/).
