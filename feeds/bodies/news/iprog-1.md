But first, in case you haven’t encountered Scrimba before, it is an online, interactive coding platform which uses a proprietary format for its lessons. Rather than using video, a “scrim” (short for screencast + interactive media) records the instructor's keystrokes, cursor movements, file changes and voice audio and runs inside a built-in browser-based code editor complete with a file tree, preview pane, and console. The advantage it offers is that the learner can pause a lesson at any point, click directly into the instructor's code editor, and change or experiment with it. Such changes are saved in a separate personal sandbox and modified code can be run to see what happens. When the lesson is resumed it carries on from where it was interrupted.
