### Book Watch  

* * *

[ The Art of Code (Manning) ](<https://www.i-programmer.info/book-watch-archive/19248-the-art-of-code-manning.html>)   

Subtitled, "the surprising power of beauty in software development" ,this book argues that aesthetics can be important in programming and elegant code can yield profound practical benefits, making it easier to maintain, extend, and onboard developers, even (or especially) when you’re doing agentic coding. Sandrine Banas discusses how artful coding directly reduces bugs and increases system durability. At the heart of this book lies the “rosette model,” a structural framework that maps eight interlocking dimensions of code quality. It places durability as the foundation, with creativity at the center supported by overlapping traits like simplicity, expressiveness, and sustainability. <ASIN:1633434923 >  

* * *

[ Essential Data Structures and Algorithms in Java (Packt) ](<https://www.i-programmer.info/book-watch-archive/19240-essential-data-structures-and-algorithms-in-java-packt.html>)   

In this practical guide Joseph Su explains how to bridge theory and practice in mastering data structures and algorithms. Using Java, and focusing on real-world challenges and pragmatic solutions, Su explores foundational data structures such as arrays, lists, stacks, queues, trees, and graphs, and shows how to implement them natively and use the Java Collections Framework to build scalable applications. <ASIN:1835883702 >  

* * *

[ Putting the C in the C64 (The Far Out Zone) ](<https://www.i-programmer.info/book-watch-archive/19236-putting-the-c-in-the-c64-the-far-out-zone.html>)   

Subtitled "A Practical Guide To Programming the Commodore 64 with C and CC65", this book introduces readers to the C programming language and shows how to use the free CC65 cross-compiler to create programs for the legendary Commodore 64. John McGinnis provides explanations, source-code examples, and technical reference material, bridging the gap between modern development tools and classic 8-bit computing. You don't need to dust off a forty-year-old computer to get started. With a modern PC and a Commodore 64 emulator, you can begin exploring C64 programming today. <ASIN:B0HNBXVC7D >
