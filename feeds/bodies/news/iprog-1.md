Microcontrollers are getting more and more like single board computers, but the latest ESP development board is a Swiss Army Knife of IoT development, complete with AI. This makes it a good candidate for so many projects. Espressif has just announced the ESP-Mosaico, an ESP32-S31-based development board that has it all: 2.16-inch 480 × 480 touch display, audio codec, accelerometer, dual magnetometer. speaker, vibration motor and more. In fact, there is so much on the device that it is difficult to be sure this list covers everything of importance! All this for a reference price of $40. Although, at the moment, demand is driving the price to $100, if you want one from the initial batch.  You can also program it using AI. The one thing Espressif is not short of is software, and in this case it has created an AI coding setup targeting the Mosaico. The hardware of the Mosaico is split between two boards - the core board and the baseboard, which are connected together.  The front of the coreboard gives you some idea how packed this device is: The baseboard has most of the "big" stuff: There are also expansion connectors - as if you could possibly need more. An I/O unit with LEDs and touch buttons; and a camera unit are already available.  However, we are not talking about a bare board setup here, the Mosaico is ready to go in a good looking case, complete with interfaces.  This makes it very easy to produce a prototype, a minimum working model, or even a end-user device without having to do much enclosure design. There are already lots of complete devices on display on the Espressif site to prove the point: As[ we reported](<https://www.i-programmer.info/news/91-hardware/18785-new-esp32-s31-super-dual-risc-v-with-wifi-6.html>) when it was launched in April 2026, the ESP32-S31 is a powerful device with WiFi, Bluetooth and Zigbee plus a lot of onboard peripherals and hardware acceleration options in its own right. Recently we reported on its [ability to run Linux](<https://www.i-programmer.info/news/91-hardware/19197-the-esp32-s31-runs-linux.html>), which almost puts it into the SBC category. Espressif has produced some cased development boards before, but nothing like this. Add to all of the hardware spec the fact that it has developed a bring-your-own-AI feature, means it is an obvious tool for the production of vibe-coded apps. For example;

    Download the code from this repository: https://github.com/esp-mosaico/esp-mosaico-vibe Set up the environment and implement a Snake game.

Compared to alternatives, Espressif majors on software. There are a very large number of packages from the basic IDF C API, ADF for audio, Matter, the HomeKit automation SDK, and so on. In contrast to Raspberry Pi and Arduino, Espressif seems to understand that supporting software is important. Comparing the Mosaico to offerings from Arduino and Raspberry Pi there is no competition. Arduino has more powerful dual-processor AI-capable boards, but not with the range of peripherals that the Mosaico offers. Raspberry Pi currently doesn't have any similar offerings and offer very little in the way of software support.  If you can get a Mosaico for anything close to $40 it's a no brainer - get one just in case you need to vibe-create hardware devices.
