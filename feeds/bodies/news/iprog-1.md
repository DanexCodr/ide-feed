Red Hat has released Red Hat Developer Hub 2.1, the latest version of its developer portal. This version expands release support to a 10-month lifecycle window, has a modernized plugin architecture and increases the support for agent-assisted development. Red Hat Developer Hub is a developer platform based on Backstage, an open source Cloud Native Computing Foundation (CNCF) project. The hub includes a self-service portal, standardized software templates, dynamic plug-in management, enterprise role based access control (RBAC) and premium support. The hub is integrated with Red Hat OpenShift so includes artificial intelligence (AI) and cloud native application architectures. The integration includes the provision of OpenShift operators and access to technologies for application development such as service nesh, serverless, GitOps, and distributed tracing. This release increases the support for agent-assisted development as it exposes Developer Hub context, software templates, and actions to MCP-compatible AI tools and autonomous coding agents. It also adds an AI catalog that lets platform teams catalog AI models, agents, MCP servers (running on Red Hat AI), skills, and governance rules with standard ownership and lifecycle policies. The front end and plugin architecture has also been modernized, with a new blueprint-based/new frontend system architecture that is now fully generally available. Plugin stability has also been improved. There's a new visual Extensions catalog that can be used to discover and enable plugins instead of manually editing config files. YAML support for declarative customization is another area to have been improved. Developers can now customize catalog entity pages, tabs, and cards in app-config.yaml using the New Frontend System without modifying application source code. The NFS (new frontend system) can also filter entity cards and tabs by entity kinds (Component, API, User, Group) or metadata attributes. The YAML improvements also mean that Red Hat Developer Hub Local supports PostgreSQL without editing compose.yaml.
