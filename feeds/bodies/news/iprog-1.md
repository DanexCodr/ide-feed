Camel 4.23 has been released with a number of improvements including the addition of semantic EIPs, new authorization components, and new Switch and Cache EIPs in Camel Core.  Apache Camel is an application integration tool that you can use to define routing and mediation rules in a number of domain-specific languages, including a Java-based Fluent API, Spring or Blueprint XML Configuration files.  Camel uses URIs (Uniform Resource Identifiers) to work directly with any kind of Transport or messaging model such as HTTP, ActiveMQ, JMS, JBI, SCA, MINA or CXF, as well as pluggable Components and Data Format options. It includes several hundred components that are used to access databases, message queues and APIs. Enterprise Integration Patterns (EIPs) are used to implement standard patterns for routing, filtering, splitting, aggregating, and transforming messages. It has multiple DSL (domain specific language) options, and lets developers write routes for integration using fluent Java, YAML, or XML. Camel 4 was released last year with Java 17 as the new baseline, and support for Java 21 was added in version 4.2. Camel 4 introduced a unified approach to configuring beans in Java, XML, and YAML. Camel CLI (JBang) was significantly improved in Camel 4 with new migration tools to convert Camel routes between DSLs (XML/YAML) and to assist in migrating OSGi blueprint and Spring XML files. Version 4 also added support for plugins, with initial camel-k commands for managing Camel K integrations, and dedicated infra and update commands for managing external services and upgrading Camel versions. Version 4.23 is a major release, with changes starting with the inclusion of Semantic EIPs. A new semantic language lets routes make decisions on the meaning of a message (classify, score, detect prompt injection) and use those decisions in Choice, Filter, Switch, Aggregate, and error handling.  There are also new authorization components for Open Policy Agent, OpenFGA and SPIFFE, so "who is calling" and "what may they do" become route steps and route policies. These components are also used for AI agent tools. Camel Core has new Switch and Cache EIPs, a pluggable KeyValueRepository SPI, error messages that point to the line in your source file, and a much more robust dev mode reload. The new Switch EIP is a fast, literal value-based dispatcher that evaluates a selector expression once and sends the message to the endpoint of the case with the matching value. The Camel TUI source editor now supports Java and XML routes - the previous version was limited to YAML - and routes can be converted between YAML, XML and Java without running them. There's also more support in the validator which now explains what to write in many more cases. A new component and language has been added for vendor-neutral feature flagging using the OpenFeature specification, with support for boolean toggles, A/B testing and fractional rollout. Camel 4.23 is available now.
