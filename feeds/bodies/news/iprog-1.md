GitHub's Octoverse 2026 Report points to a surge in developer activity driven by AI. Overall commits on the platform saw a historic explosion, reaching 34.3 billion, up from 12.9 billion in 2025. Productivity rocketed with repositories using agent configurations logging eight times as many commits on average compared with those without.  As this graph shows there was a distinct change of gear in June 2026 and this GitHub attributes to the increase in the number of pull requests initiated with an AI agent. In March the proportion was 17% and by September this has risen to 40%.  Developers also relied on automations to keep projects moving. GitHub Actions ran a job 1,440 times every second during the year - which ran from October 2025 to September 2026. This equals 124 million times a day and is more than three times last year’s total. Developers merged more than 30 million Dependabot pull requests to keep dependencies current and reduce the use of known vulnerabilities, about double 2025’s pace. The GitHub community also grew. GitHub now serves more than 225 million developers. The United States (38.3 million) and India (32 million) remain the two largest developer communities, and each added more than 10 million developers this year. Brazil added 3.28 million developers on GitHub this year, the third most of any country. There was also rapid growth across India, Morocco, and Indonesia, which the Octoverse team claims is driven largely by accessible AI coding interfaces. AI-powered development tools are successfully lowering barriers to entry, enabling "citizen developers", in the Octoverse Report's terminology, domain experts and non-traditional coders to fuel expansion of software creation beyond traditional tech sectors, notably healthcare, mining, construction and agriculture, to employ "vibe coding" to build applications and automate workflows. While GitHub regards the expansion of its community and the growth in activity as beneficial, there are caveats which are expressed on the[ GitGuardian blog](<https://blog.gitguardian.com/github-octoverse-2026>). Firstly, with the help of AI agents code is being written three times faster than anyone can review it. Secondly, citizen coders now ship apps wired to business systems with API keys they have never been taught to protect, pointing out that Claude Code-assisted commits already leak secrets more often than human-crafted commits. This post concludes: _As software development and automation continue accelerating, detecting exposed credentials, remediating existing risks, and preventing new exposures must become part of everyday development workflows._
