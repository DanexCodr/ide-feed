These articles are about using a Linux workstation to develop
bare-metal applications for a PC-type computer with UEFI firmware. They
are written for experienced Linux developers, but assume no prior
knowledge of UEFI. The articles cover the software tools needed, how to
compile and link, how to create a bootable disk, and basic file
management.

Please note that I wrote these articles to be read in order. Each one
relies on information from the previous articles, and it might be
difficult to follow them out of sequence.
