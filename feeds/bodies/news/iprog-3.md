JCON Europe, the annual, community-driven conference for Java developers organized by Java User Group Oberpfalz and _JAVAPRO Magazine_ , took place in Cologne, Germany, from April 20–23. We provide an overview of this year's event. This year the conference explored modern Java development, highlighting advancements in virtual machine internals, performance tuning and innovative functional programming concepts alongside the integration of artificial intelligence within integrated development environments. Experts discussed how frameworks like Quarkus and LangChain4j streamline the implementation of generative AI and Retrieval Augmented Generation and emphasized the critical role of Model Context Protocol servers in supplying accurate contextual data. Furthermore, discussions covered software architecture documentation, stressing the importance of maintaining concise and discoverable architectural decision records using Markdown. Finally, presenters underscored the continued value of community engagement, community driven user groups and the indispensable role of human oversight in collaborative, AI assisted software lifecycles. Here's an overview of the key subjects: The dominant topic was of course AI and AI assisted engineering. Speakers repeatedly noted how AI hype and generative tools are actively refactoring developer identity, IDE workflows, code generation, enterprise frameworks and system design across the Java ecosystem. Among those topics were: **AI powered Java development, agentic frameworks and interoperability protocols** Sessions compared Java AI frameworks such as LangChain4j, Spring AI, InBabel and Cook, analyzing how Java developers can build AI applications within native JVM environments rather than switching to Python. Protocol standards like Google's A2A (Agent-to-Agent) for inter agent collaboration and Anthropic's MCP for tool and context integration were featured prominently as key building blocks for multi agent systems. Presentations also explored Retrieval Augmented Generation , unstructured data extraction with Apache Camel, embedded vector search (such as JVector and Eclipse Store) and local LLM execution via Ollama. Speakers also discussed maintaining Clean Architecture principles and using Architectural Decision Records (ADRs) to keep systems maintainable when incorporating AI tools. As such, the following three talks provided particularly unique, contrarian, or highly innovative perspectives compared to the rest of the conference program: VIDEO **1\. "A Developer's Search for Meaning: Thriving as AI Transforms Our World"**  
Speakers: Markus Westergren and Elma Westergren Rather than focusing on code benchmarks or framework syntax, this session evaluated AI disruption through occupational therapy, healthcare science and human identity. Drawing from Rory Sutherland’s book Alchemy, Elma illustrated how a hotel consultant recommended replacing a doorman with automatic doors to save money, causing the lobby to fall apart because no one was left to greet guests, direct traffic, or hail taxis. They argued that management faces the same delusion; viewing code typing as "door opening" and assuming AI replaces developers, while ignoring invisible responsibilities like stakeholder negotiation, architecture trade offs and incident ownership. Citing Garry Kasparov’s defeat by Deep Blue and his subsequent creation of Centaur Chess (combining human strategy with machine calculation), the speakers argued developers must shift from raw code generation to becoming "AI Shepherds" who guide autonomous systems through complex domain constraints. **2\. "Does AI Make Us Less Intelligent?"**  
Speaker: Jan Thierolf This talk examined AI adoption using neuroscience, cognitive psychology and psychometrics. Thierolf compared AI reliance to spatial navigation studies showing that heavy GPS usage shrinks hippocampus dependent cognitive mapping and degrades natural way finding skills. He highlighted the Reverse Flynn Effect,recent data showing a decline in human IQ scores across logic, vocabulary and problem solving, with the steepest drops in 18 to 22 year olds. He warned that the shift into the Era of Agentivism (where knowledge is executed inside an autonomous black box rather than located or prompted) prevents developers from building mental models of their applications, triggering "automation surprise" when systems hand control back during critical failures. **3\. "You Gotta Keep the Dogs Away: YOLO Developer Workflows with a Coding Agent in a Box"**  
Speaker: Kevin Wittek Wittek explicitly rejected the prevailing industry consensus that developers should maintain constant "human in the loop" oversight over AI agents. He argued that requiring human approval for every terminal command is a dystopian illusion that turns developers into box pigeons clicking "approve" under variable ratio reinforcement. In practice, developers become mere "accountability sinks" so vendors can shift liability when generated code breaks. Instead of micro managing agents, Wittek advocated for unsupervised "YOLO Mode" (dangerously-skip-permissions), isolated inside Docker Sandboxes,ephemeral microVM environments with bidirectional file sync, network egress controls and secret proxying, allowing agents to iterate freely and run tests until a task is completed safely.
