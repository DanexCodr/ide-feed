This release expands Codex support in the agent host, so you can keep the same coding session while changing where and how you work. The improvement is mainly aimed at people who use Codex with both a GitHub Copilot subscription and a ChatGPT subscription. If you sign in to both, you can switch between Copilot-backed and ChatGPT-backed models from the model picker without losing the current conversation. The team says that if you aren't signed in to GitHub Copilot and want to use the Codex harness just with your ChatGPT subscription, you also have to enable the flag to allow access. You can also move the same Codex session between the ChatGPT app and VS Code instead of starting a new conversation, and interact with desktop apps from VS Code, so long as the ChatGPT app is installed and configured for computer use. This works with models from either your Copilot subscription or your ChatGPT subscription. Another improvement lets you run an agent session inside a local folder's Dev Container. The agent uses the environment and dependencies configured for the project instead of those on your local machine. When the setting is enabled, local folders with a supported Dev Container configuration automatically show a folder menu with a Use Dev Container action. For this to work, Docker has to be installed on your machine. New in preview for this release is a way to keep completed sessions organized. The team says the new feature is designed to keep finished work out of the way while preserving the conversation for later. The way it works is that when all of an inactive session's pull requests have merged, the Agents window can suggest marking the session as done.
