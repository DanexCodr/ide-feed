A local video-production workspace driven by the **`/devrel-video` Claude Code skill**. Capture real product interactions with Playwright CLI, compose title cards, chapters, and CTAs with HyperFrames, then master and inspect the result with FFmpeg. Start with a silent walkthrough; add narration, music, subtitles, or your own presenter footage when needed.

## Quick start

**For planning:** Git and authenticated Claude Code. Clone the full workspace so its native skill and project layout stay together:

```
git clone https://github.com/aaitor/skill-video-studio.git
cd skill-video-studio
claude
```

Ask Claude:

```
/devrel-video Prepare a 25-second silent walkthrough brief for the bundled
Acme app: show the workspace, filter by category, then open a project.
Reuse brands/acme. Show the plan before capture or rendering.
```

Expected result: a project brief and a concrete beat plan. For a complete video, install the [capture/render prerequisites](https://github.com/aaitor/skill-video-studio/blob/main/docs/installation.md#capture-and-rendering-prerequisites) and follow the [worked walkthrough](https://github.com/aaitor/skill-video-studio/blob/main/projects/example-walkthrough/README.md). The production stack needs Node.js 22+, FFmpeg/ffprobe, Chromium, and the helper-specific Python dependencies. Optional narration and avatars require your own additional services or GPU setup.

- Real product capture: browser interaction scripts with explicit beats and stable selectors.
- Branded composition: title, browser frame, chapters, and CTA in a HyperFrames timeline.
- Local mastering and QA: master/web copies, ffprobe checks, contact sheet, and thumbnail.
- Optional audio: six local music styles, narration-driven timing, and voice variants.
- Optional presentation: subtitles, private bring-your-own presenter footage, and terminal/browser sequences.
- Source-based workflow: reusable brands, briefs, templates, and two complete worked examples.

Portrait/social output profiles remain on the roadmap. Full capture/render depends on your local toolchain; offline CI checks sources and selected local utilities, not the complete production stack. See [workflow](https://github.com/aaitor/skill-video-studio/blob/main/docs/workflow.md) and [usage](https://github.com/aaitor/skill-video-studio/blob/main/docs/usage.md).

## Configuration

Each video uses `projects/<slug>/brief.yaml`, brand tokens under `brands/<name>/`, and generated output under its project folder. Optional private settings live outside Git, selected by `DEVREL_VIDEO_ENV`.

| Setting | Purpose |
| --- | --- |
| `brief.yaml` | Product URL, audience, message, beats, brand, duration, and optional layers |
| `ORPHEUS_URL` / `ORPHEUS_KEY` | Your optional narration endpoint and token |
| `AVATAR_HOST` / `LS_DIR` | Your optional SSH GPU host and LatentSync checkout |
| `BGM_STYLE` | Local background-music style; default `corporate` |

See [configuration](https://github.com/aaitor/skill-video-studio/blob/main/docs/configuration.md), the [actual brief template](https://github.com/aaitor/skill-video-studio/blob/main/.claude/skills/devrel-video/templates/brief.example.yaml), and [security/privacy guidance](https://github.com/aaitor/skill-video-studio/blob/main/docs/security-and-privacy.md). Keep private footage and credentials outside this public repository.

Brief → explore → brand → capture → compose → optional layers → render/QA → thumbnail. The [skill](https://github.com/aaitor/skill-video-studio/blob/main/.claude/skills/devrel-video/SKILL.md) coordinates existing tools rather than replacing them. Detailed production steps are in the [workflow guide](https://github.com/aaitor/skill-video-studio/blob/main/docs/workflow.md) and [production notes](https://github.com/aaitor/skill-video-studio/blob/main/.claude/skills/devrel-video/references/production-notes.md).
