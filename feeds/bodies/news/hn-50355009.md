Ever rebooted and lost a dozen tmux windows, along with the agent conversations running in them?
tmux-restore saves everything every minute and right before shutdown, and puts it back when tmux
starts. Panes running Claude Code, Codex, Gemini CLI, opencode or pi reopen the exact
conversation they were in.

[![A tmux window with Claude Code, vim and a dev server. tmux is killed and started again: the conversation, vim and the layout come back, and the dev server's command waits on the prompt.](https://github.com/andrewboldi/tmux-restore/raw/main/assets/demo.gif)](https://github.com/andrewboldi/tmux-restore/blob/main/assets/demo.gif)

## What it does

- Everything comes back. Sessions, windows, splits, working directories and scrollback.
- Agents resume mid-conversation. Each one reopens its own conversation, with the same flags.
- Saved at shutdown, not just on a timer. Every minute, plus once more as the machine goes down.
- Nothing risky re-runs. Editors and monitors restart. Anything else (a deploy, a dev server) comes back typed on the prompt, waiting for Enter.

## Install

```
curl -fsSL https://raw.githubusercontent.com/andrewboldi/tmux-restore/main/install.sh | bash
```

It installs whatever is missing (tmux, TPM, the plugins) and turns everything on. Run it again to
update.

## How it works

1. Save. Every minute, tmux-resurrect records every session, window, pane and its scrollback.
2. Rewrite. For each pane running an agent, a small adapter finds the conversation's id in the agent's own session files and saves the command that resumes it.
3. Shutdown. A background service (systemd on Linux, launchd on macOS) saves once more the moment the machine starts going down.
4. Restore. When tmux starts, tmux-continuum puts it all back, and the agents reopen their conversations.

More in [how it works](https://github.com/andrewboldi/tmux-restore/blob/main/docs/how-it-works.md). Using another agent? An adapter is one short file;
see [CONTRIBUTING.md](https://github.com/andrewboldi/tmux-restore/blob/main/CONTRIBUTING.md).
