At the Android Dev Summit last week the focus was split between yet more AI-related features and ways to create and ship better performing apps.For Android developers, however, the announcement that there's a new stable version of Android Studio Rabbit 2 is probably the more important news.  The AI-related improvements included the ability to use different coding agents and models within Android Studio. Improvements to the Android CLI were also announced. The Android Dev Summit is Google's official conference for Android developers. It last ran in 2022, but was back on this year on October 28–29 with the main event at Google HQ in Mountain View, California, alongside a satellite event in London.  The stable version of Android Studio Rabbit 2 is described as ready to use in production, with improvements including Bring Your Own Agent (of which more below), new XR Emulator features, a LeakCanary update, a new agent skills manager tool, and AI code review.  The bring your own agent feature means developers can choose from around 40 coding agents, including Claude Agent, Codex from OpenAI, Junie, and Google Antigravity. These agents have access to Android Studio tools like the Android Emulator, Build Systems, Logcat, and can also use Android skills to complete complex tasks. One problem raised by the wide range of potential models and agents is working out which one is right for your project. In view of this, another announcement at the conference was Android Bench 2.0. Bench 2.0 is an LLM leaderboard which evaluates how models and agent harnesses perform on long-running, real-world Android development tasks, such as migrating an app's UI or building a new app from mocks.  The Android XR Emulators for XR glasses, audio glasses, and display glasses are now stable in Android Studio and have some new and updated features. The updated display glasses Emulator lets you customize the environment with your own 360-degree photos or video feed from a connected camera. There are also new hardware LED indicators for microphone and camera states, and the Pairing Wizard can now pair a virtual phone with virtual audio and display glasses faster and more reliably.  VIDEO The skill manager has also been improved to make it easier to discover, install, and manage Android skills, and Studio comes with some Android and Firebase agent skills such as migrating legacy XML Views to Jetpack Compose, upgrading to AGP 9, implementing adaptive layouts for foldables and tablets, and integrating CameraX and Firebase services. Android Studio also has a new agentic code review feature to make it easier to review large changes your agents made and understand exactly what the AI has done. If you ask for a review session for pending agent changes or the Git changes window, Android Studio now generates a report of potential issues, and there's the option for an AI-guided walkthrough to understand longer changes, and have your agent fix the issues it finds. Other announcements at the conference included the release of an official Android plugin for Google Antigravity, Google's agentic development platform. The plugin includes Android CLI, official skills, and it has been updated with "deep platform integrations featuring interactive tools that appear right alongside your conversation, powered by Android CLI".  There are also Android plugins for Claude Code and Codex from OpenAI. The plugin makes the CLI tools and instructions available to the coding agent so it can create Android projects, manage emulators and virtual devices, inspect live UI layouts, run Journeys, browse and install official Android skills, and search the official Android Knowledge Base.
