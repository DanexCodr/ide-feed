Couchbase has announced a major expansion of its AI Data Plane with new capabilities including native Amazon Bedrock integration with semantic caching, managed Agent Memory and a managed MCP server on AWS. Vector search has also been added to Couchbase Operational Insights.  Couchbase is a distributed, multimodel, NoSQL cloud database that combines the properties of a distributed document database (JSON) with features of a traditional DBMS including distributed SQL, transactions, and ACID guarantees. Its AI Data Plane is the governed memory and data layer connecting AI agents to context, tools, and storage; this feature began life as Couchbase AI Services, or Capella AI Services for its managed tier.  The aim of the expansion is to give enterprise teams a single governed platform. The company says this can replace fragmented data services that slow agent deployments, so reducing infrastructure burden and the cost of running production AI at scale. Couchbase's reasoning is that agents have become the primary consumers of enterprise data infrastructure, and most of that infrastructure was not built for them. The company quotes data showing that machine traffic surpassed human traffic in June 2026, with 57.5% of web requests now automated rather than human-initiated. They say agents generate 450% more data-layer traffic per task than humans performing the same work, and 83% of organizations report needing infrastructure upgrades before they can run production-grade agentic AI. Because most production databases were designed for human-scale query patterns, predictable throughput, and data that lives in one place, they struggle with the highly concurrent nature of agent requests. These often need both operational and historical data, and increasingly operate where the data is generated, whether at the edge, on devices, or across regions. The improvements to the data layer start with the addition of native Amazon Bedrock integration with semantic caching. This enables serverless, pay-per-token access to hundreds of foundation models along with vectorization over private networking. Inference and embedding generation now run alongside the data, without separate GPU instance management or overhead. The Couchbase team says this provides a path to semantic caching for applications and agents built on Bedrock, where semantically similar queries are served from cache instead of re-invoking the model. The second improvement is the addition of managed agent memory and a managed MCP server on AWS. Couchbase launched Agent Memory and an enterprise-supported MCP server as self-managed capabilities in June, and is now offering both as fully managed cloud services on AWS. Managed agent memory gives agents a durable, low-latency memory layer that persists profiles, conversation history, and vectorized facts across sessions, so agents pick up where they left off on a new sessions. The managed MCP server gives agents and tools a governed, open-standard path to Couchbase data, with nothing to stand up or operate. Both are framework-agnostic, and validated with LangGraph, CrewAI, and LlamaIndex, so engineering teams can switch or combine orchestration frameworks without rebuilding their memory layer. The third element of the expansion is support for vector search in Couchbase Operational Insights. This is a real-time analytical database (RT-OLAP) and JSON-native NoSQL analytics service that is designed for organizations that want to run complex analytical queries directly on live operational data without slowing down transactional applications. Increasing query volume requirements by agents, and the need for enhanced data freshness means pattern recognition across structured and unstructured data must be completed in a single pass.  Couchbase Operational Insights now supports vector search alongside structured analytical queries against fast-moving operational data. Teams can run semantic and structured analysis together, segmenting by meaning with vector search and then aggregating the results in a single SQL query, with no ETL pipeline and no secondary system to synchronize. By combining traditional analytics queries built from counts, sums, and group-bys with vector searches looking at unstructured, nested JSON, Couchbase supports queries that previously required multiple systems. The company says a query like "revenue by region, filtered by clusters of frustrated customers" resolves in one pass because JSON is analyzed in place and never flattened. Couchbase's write-back function then sends query results straight into the operational data that applications and agents already read, making insights more useful.  Couchbase says customers who have converged fragmented data services onto a single platform report TCO reductions exceeding 50% across more than half of deployments. The AI Data Plane extends that because one platform now serves caching, documents, queries, search, analytics, and AI context against a single copy of the data.  The new services and capabilities are available now.
