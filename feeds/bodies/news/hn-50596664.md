A book, in PDF and EPUB, that writes the Lean proof of the Riemann Hypothesis in [tamnd/riemann-lean](https://github.com/tamnd/riemann-lean) as mathematics: definitions, theorems, lemmas and their proofs, in words.

The claim is not checked. Nobody has built the Lean project in full yet, and no person has checked the written statements against the Lean code. This book explains the Lean code. It is not a separate check of the mathematics. See [What is checked](https://riemann.tamnd.com/trust/).

|  | Volume | Source |
| --- | --- | --- |
| 0 | Guide: how to read, the status of the claim, notation, the named results, the index of Lean names | `content/front/` and tamnd/riemann |
| 1 | Background: the mathematics that the proof uses, in 17 chapters | the Learn pages of tamnd/riemann |
| 2 | The proof: the top of the proof, its chapters and steps | the written proof of tamnd/riemann |
| 3 to 12 | The Lean development, one branch or one Lean folder in each volume | `content/dev/`, written for this book |

The books are in the [releases](https://github.com/tamnd/riemann-handbook/releases).

Each declaration of the proof is inside the dominated subtree of exactly one other declaration (its immediate dominator, in the graph of uses from `riemannHypothesis`). The ledger gives an entry to each declaration whose dominated subtree is large, in tiers: 1,000 or more declarations (591 entries), 300 or more (1,927), 100 or more (5,764). It assigns each entry to a volume by its branch of the proof or by its Lean folder, and to a chapter by its Lean folder. In a chapter, the entries come from the top of the proof down.

```
python -m rhb ledger --records /path/to/records --min 1000 --write
```

`ledger/coverage.md` has the numbers. `prompts/entry.md` is the brief for the writers of entries.

## Build

You need Python 3.11 or later, [pandoc](https://pandoc.org) 3.8 or later and [Tectonic](https://tectonic-typesetting.github.io). Put tamnd/riemann and tamnd/riemann-lean next to this repository.

```
pip install .
python -m rhb survey
python -m rhb check
python -m rhb build --volume 0,1,2 --formats pdf,epub
```

The books go to `build/`. The pipeline is that of [The Handbook of Algorithms](https://github.com/tamnd/algorithm-handbook): Markdown, then pandoc with `filters/rhb.lua`, then LaTeX with `tex/handbook.sty`, then Tectonic. The EPUB is EPUB 3 with MathML.
