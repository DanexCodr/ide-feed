## Render routes on the server

Export `runtime = "server"` to render a route and its async components on the server. The browser loads a 21 kB (gzip) frame player instead of your app.

```
1import { Suspense } from "react";2import { Box, Text } from "@textjs/app";3import { db } from "@/lib/db";45export const runtime = "server";67async function Deploys() {8  const rows = await db.deploys.latest(5);9  return rows.map((d) => (10    <Text key={d.id}>{`${d.state}  ${d.branch}`}</Text>11  ));12}1314export default function Page() {15  return (16    <Box className="flex-col p-1">17      <Text bold>Deployments</Text>18      <Suspense fallback={<Text color="muted">Loading…</Text>}>19        <Deploys />20      </Suspense>21    </Box>22  );23}
```

- Partial PrerenderingEvery static route’s first frame ships inside its HTML. The console paints before JavaScript loads.
- Middleware`middleware.ts` runs before matched requests, with `NextRequest`, `NextResponse` and `config.matcher`.
- Caching`revalidate`, `unstable_cache` and `revalidateTag` cache route handlers and data, with stale-while-revalidate.
- Deploy adapters`text build --adapter` targets `static`, `bun`, `vercel` or `cloudflare`. Server-rendered routes need `bun` or `text start`.

## Also runs in terminals and agents

Turbolog writes each frame as `%c` spans in one `console.log`.

`text run` renders the same App Router app in truecolor ANSI and runs route handlers in-process.

Over MCP, agents navigate routes, press keys and read each frame as plain text.

## Code with OpenCode in DevTools

OpenCode Lite is the OpenCode TUI rebuilt with Text.js to run in your browser console.

### Sandbox

A scripted agent answers any prompt, with nothing to install.

### One command

Run `bunx @textjs/opencode@latest proxy` and enter the code it prints. The page connects to OpenCode on your machine.

Pick any model your server has configured with `/models`. Sessions, agents and models come from your OpenCode server.
