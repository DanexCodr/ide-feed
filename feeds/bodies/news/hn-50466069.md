A few days ago I was scrolling through HN when I saw a landing page that gave me a little deja vu. It was for [KetchUp](https://ketchup3d.github.io/app/), a SketchUp alternative. I remember playing with Sketchup back when it was still a Google-branded program running on my school’s Win7 machines, but that wasn’t the only reason the landing page looked familiar. It was the north-east arrow (↗) littered everywhere. 3 links to the `/play/` page all had the arrow (“Try in browser ↗”, “Open the workspace ↗”, “Let’s make something ↗”).

I left a comment on HN:

While building [Timewarp](https://arsh.zip/posts/timewarp/), I noticed that Astra would sprinkle this Unicode character everywhere, and I would shout at it: “No! Arrows only for external links!” I had a hunch that Astra was the culprit here too, since I’ve mostly been using Opus, Sonnet and DeepSeek for the last few weeks and had forgotten about the arrows entirely.

So I did what any reasonable engineer would do: burn tokens and time to prove my hunch right.

### Counting arrows

I could prompt every model a few hundred times to figure this out, which was what I initially set out to do. But then I realized I could do better by sampling public repos on GitHub. I had Claude sample about 4k repos created between November 2025 and last week.

So it's real. About 1 in 20 new web repos had one at the start of the year. Since September it's closer to 1 in 6. But who's behind it?

### Finding the culprit

Thanks to AI attribution that harnesses add in commits it was trivial to find out who was (mostly) littering the web with arrows. I ended up with 1,687 commits that added at least 30 lines of UI code.

At Anthropic's peak in May, about 1 in 10 Claude UI commits added an arrow, and Opus 4.8 was the most arrow-happy model at 9.7%. Then it went down. With Opus 5.5, only about 2% of commits have an arrow.

### OpenAI went all in

Codex doesn't specify the model in the commit byline, so the best I could do was add model release dates to the graph.

About 1 in 4 UI related commits add an arrow! My gut was half right. Astra definitely loves the arrow, but the trend started in July with GPT 5.6.

### Pointing inwards

What stood out about OpenAI's usage is that it seems to liberally slap the arrow on links that don't go to a different domain. I didn't have a lot of data to verify this, but in a very small sample of 57 commits where the arrow sat on a link, Codex's arrows pointed to an internal link 63% of the time (19 of 30), while Claude's pointed inwards only 33% of the time (9 of 27).

### The caveats

I don't know where this tic comes from. I'd never seen anyone use that arrow for an internal link before LLMs were making websites, so it's interesting to think about why they use it so much. Maybe someone at OpenAI just likes arrows.

This is all based on public GitHub data from commits that have AI attribution. To filter UI-related commits, I had Claude search for terms like `landing page | footer | hero`, so this is mostly a small sample of LLM-authored landing pages. That said, around 4,000 public repos were sampled, and all the data is here: [arshzip/arrows ↗](https://github.com/arshzip/arrows)
