The Agent Plugin is part of Jfrog's AI supply chain solutions designed to secure and govern AI-assisted software development. The main issue with AI coding agents like Claude Code and Cursor is that they can bypass traditional security perimeters and create software supply chain security blind spots, primarily by changing how software dependencies and tools are discovered, retrieved and executed: **Bypassing governed repositories** : Traditional development workflows route software dependencies through hardened, controlled internal repositories. In contrast, AI coding agents convert natural language prompts into code and autonomously pull required libraries, database drivers and frameworks directly from public registries (such as npm, PyPI, Maven, Go, Docker Hub and NuGet) by default. **Evading security scanning and governance:** Because agent driven downloads occur outside an organization's controlled repositories, critical security controls including vulnerability scanning, curation policies, license compliance checks and audit logs are skipped, creating an ungoverned shadow dependency channel. **Exploitation via "slopsquatting":** Research shows that nearly 20% of AI generated package recommendations reference non existent packages. Attackers exploit this through slopsquatting, registering malicious packages under names that AI models frequently hallucinate. **Unvetted ai assets and primitives:** Beyond traditional software packages, agents independently discover, invoke and consume external Model Context Protocol (MCP) servers, agent skills, plugins and third party AI services without prior enterprise security review. **Velocity outpacing human oversight:** AI agents make automated runtime decisions and generate code or binaries faster than human review cycles and manual security gates can keep up. To mitigate these risks, tools like Agent Package Resolution, a feature of the JFrog Agent Plugin (available for coding assistants like Claude Code, Cursor, VS Code and Codex) are designed to bring AI driven software downloads under enterprise governance. Instead of allowing coding agents to pull dependencies directly from public registries, Agent Package Resolution automatically routes package requests through your organization's JFrog Artifactory repositories. Specificaly, Agent Package Resolution enforces security and governance through three complementary layers: **Session steering (context injection):** At the start of each agent session (SessionStart), the plugin inspects the environment and injects routing policies along with resolved Artifactory URLs directly into the coding agent's session context. This instructs the agent to prefer internal Artifactory repositories over public registries for all requested packages. **Persistent package manager configuration (jf setup):** To ensure indirect and transitive downloads are covered, a one time command (or automated zero touch setup) binds local package managers (e.g., npm, pip, docker) to Artifactory. This layer persists on the machine across sessions and command line tools, ensuring that indirect installs such as postinstall scripts or pip install -r commands route to Artifactory automatically. **Server side curation and scanning enforcement:** Regardless of whether an agent follows prompt instructions, every request directed to Artifactory hits server side JFrog Curation and JFrog Xray security gates. Malicious packages, unapproved open source licenses and vulnerable dependencies are blocked at the repository level before reaching the developer's machine. The JFrog Agent Plugin then, which serves as a lightweight developer integration that bridges popular AI coding assistants directly with the JFrog Platform, equipps them with domain specific JFrog Platform Skills to transform them into "supply chain aware participants" that enforce security and compliance, natively inside the developer's IDE. So Agent Package Resolution aside, the plugin also enforces: **Real time upstream governance:** Subjects all agent requested packages to server side JFrog Curation and JFrog Xray security checks blocking malicious packages, license violations and vulnerable dependencies before code is pulled. **Governed mcp servers and skill execution:** Connects with JFrog Agent Guard to evaluate tool and skill calls, ensuring agents only connect to approved Model Context Protocol (MCP) servers and policy compliant skills. **In IDE natural language operations:** Allows developers to execute routine DevOps and DevSecOps tasks such as querying repository metadata, checking CVE details, managing access tokens and running security audits directly through conversational prompts. **End to end auditability:** Maintains full visibility and audit logs for every artifact, tool invocation and package download requested or executed by an AI agent.
