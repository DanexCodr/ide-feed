Microsoft has released .NET 11 Release Candidate 2 with updates to F#, MAUI and various libraries. As with RC1, this release includes a go-live support license, so it can be used in production applications. .NET is the platform created from a combination of .NET Framework and .NET Core, including C# and F#. The previous release, .NET 10, was released in November 2025 and as a long term support release that will be supported for three years. .NET 11 will have two years of standard term support (STS).  The go-live support license means organizations can use the release candidate knowing that Microsoft will provide official technical support and troubleshooting if problems occur after launch.  This release of .NET 11 is supported in the new Visual Studio 2026 Insiders release alongside Visual Studio Code with the C# Dev Kit.  Areas changed in this release include F#, MAUI, Windows Forms, and a number of libraries. F# changes start with the addition of runtime async support. F# now has compiler-recognized return and await intrinsics for generating runtime-async methods. The runtime manages asynchronous suspension and continuation instead of requiring a compiler-generated await state machine. SRTP for extension members and operators has also been added to F# as a preview feature. This means developers can bring existing .NET and third-party types into generic F# algorithms without changing those types or introducing wrappers. Statically resolved type parameter (SRTP) constraints can select extension members, including operators, supplied by your code or a library.  Other improvements include lower allocations in FSharp.Core collections. so ,more List and Array traversal functions, including fold, exists, and tryPick, can now inline their callback lambdas. This removes callback closures from common collection operations in your applications. There are also improvements to compiler memory usage improvements, and to trimming and native AOT.  .NET MAUI also has some improvements. You can create an app with a C# UI without needing an additional C# UI library. Developers can also use Apple Icon Composer assets, and there's an opt-in Shell handler on Apple platforms. XAML authoring has also been improved RC 2 refines the visual styles introduced during for Windows Forms in .NET 11 previews and adds Designer-guiding analyzers for C# and Visual Basic.  Improvements to libraries see new APIs for incremental CBOR reading, cryptography, validation messages, and HTTP/2 concurrency. CBOR (Concise Binary Object Representation) is a binary data serialization format that provides JSON-like data models with smaller message sizes and faster processing.  There are also experimental composite ML-KEM and HPKE APIs. NET 11 Release Candidate 2 is available for download now. '
