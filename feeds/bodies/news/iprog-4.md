This new course explores the evolving landscape of AI agent evaluation and training, highlighting a transition from simple language models to complex, multi-step systems capable of handling long-horizon tasks.   
This course and workshop series, organized by Hugging Face, focuses on building, fine tuning and evaluating autonomous AI agents. Its central goal is to guide technical practitioners through transitioning from standard text generating language models to multi step agentic systems capable of planning, invoking tools and completing complex, long horizon tasks. Here is an overview of each tutorial chapter and workshop deep dive included in this series: **Part 1-The training Agents hands on tutorial series** Chapter 1: Fine tuning a coding agent for continual learning  
The focus is on Supervised Fine Tuning (SFT) on agent interaction traces. It demonstrates how to fine tune open weight models using real world agent traces to imitate multi turn tool calling, reasoning steps and agentic communication formats. It introduces a meta agent approach where a master agent manages parameter sweeps, tracks live metrics via Track.io and executes training remote jobs on Hugging Face Jobs. It also details token masking to ensure the model learns strictly from assistant completions rather than user prompts. Chapter 2: Model distillation for custom agents  
Its focus is on capability transfer and model compression. It breaks down post training compression from larger or domain expert teacher models to smaller, faster student models. It contrasts off policy distillation (training on static teacher generated text or logit distributions) with on policy distillation (where the student generates its own completions, evaluated against teacher prefill distributions via reverse KL divergence). It also covers self distillation (SDFT, STPO) using the TRL library. Chapter 3: Reinforcement learning  
Introduces Group Relative Policy Optimization (GRPO) as an efficient RL algorithm for agentic models. It explains how GRPO generates a group of completions per prompt and calculates relative advantages across the group (mean and standard deviation) without needing a separate value model. Chapter 4: From reward functions to environments  
Transitioning from static reward functions to dynamic RL environments, explores building Gym style, interactive sandboxes (such as OpenM) where agents perform multi step sequences of actions and observe state changes. It outlines the capability cycle (harness → benchmark → environment → training loop) and highlights the critical architectural requirement of separating execution sandboxes from verification/grading logic so agents cannot cheat or alter test suites. **Part 2-Deep dive workshops** The Agentic evaluations workshop is about overcoming the capability reliability gap in autonomous agents. Examines why high performing LLMs fail in real world deployments due to low consistency, poor calibration and benchmark gaming. It introduces dynamic multi app simulation benchmarks like Gaia 2 using action level verifiers. The RL for Agents workshop focuses on state of the art open source training paradigms and benchmarks. It analyzes the exponential growth of agent task horizons and the shift from static RLVR to asynchronous multi step RL training. It reviews open source environment frameworks (verifiers, OpenM, Harbor, Prime Intellect), Recursive Language Models (RLMs) that manage long context via REPL/code sub calls and hard, verifiable benchmarks like SWE bench, AlgoTune and Code Clash. It is obvious that the content is very technical in nature, as such it targets professionals and researchers involved in building, training and evaluating AI agents; specifically:

  * AI/ML engineers and post training researchers
  * Agent developers and software engineers
  * AI evaluation, reliability and safety researchers
  * Enterprise applied AI technical leads and practitioners

For those pros the course is exceptionally useful because it provides hands on, open source workflows spanning supervised fine tuning, model distillation, GRPO reinforcement learning and dynamic evaluation environments to close the capability reliability gap and effectively train autonomous AI agents.
