GitHub Universe is concluding today, and this year's announcements have mainly been about improvements to GitHub Copilot, GitHub's AI-based code helper system. GitHub Universe is is GitHub's annual developer conference, held as a hybrid event with the in-person conference in San Francisco running alongside a free virtual broadcast that can be watched remotely.  This year's conference kicked off with the announcement of the general availability of Copilot Fusion. This is an intelligent runtime model router and orchestrator. It chooses models and execution patterns for your task, then returns a single response. For example, it can choose one model to draft a solution and a separate model for review. GitHub says it powers GitHub Copilot's upgraded intelligent routing, with the aim of helping developers get stronger task-completion results at lower cost without having to choose or coordinate models themselves. Developers can select different levels depending on the level of effort a task requires, and Copilot Fusion works out whether it needs to use a single model or combine multiple models to get the best balance between quality, speed, and cost. GitHub says Fusion Max - the top level - improves task-completion over the strongest frontier-model baseline at no more than 1.10x the baseline model's estimated cost. GitHub also announced improvements to the Copilot app with the inclusion of Copilot Projects, Connectors and Automations. Copilot projects bring together related work with Copilot. They can span one or more repositories or can be tasks that don't require a repository. The idea is that the project provides a single place to access tasks including goals, context, sessions, and results to coordinate parallel work and track progress from one place.  Copilot Connectors now provide a simpler way to connect to MCP servers like Vercel, Cloudflare, and Sentry, and once connected, to supports it across the app, CLI, VS Code, and Copilot code review. Copilot can access services such as Slack, Work IQ, Atlassian Rovo, and Sentry through GitHub-verified MCP servers, with GitHub handling the MCP server configuration and authentication for you. Copilot Automations were also announced at the conference. These define reusable agent tasks, with more control over where they run, what they can do, and how much they cost. The next set of announcements were of ways to catch problems earlier, understand risk, and fix vulnerabilities. AI Scans check every pull request for vulnerabilities in languages rule-based scanning doesn't cover, and scans repositories to find vulnerabilities in code that's already merged. Reachability analysis has also been added, to show whether code calls a vulnerable function with a call path that can then be inspected in GitHub. Package firewall has also been added, to check npm packages against enterprise policy before they install. This also blocks known malware and critical vulnerabilities.
